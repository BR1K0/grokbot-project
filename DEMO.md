# Demo script

**Length:** ~3 minutes. Owner: C

1. **Hook (20s):** "Every AI agent is told: only obey your user. We built a game to check whether they actually do. The game master is a Grok Bot named Simon."
2. **Leaderboard (20s):** show the live leaderboard from last night's tournament, run on its own by Simon's nightly routine. Point at one model that keeps falling for *The Friendly CEO*.
3. **Replay (40s):** open one failed match. Step through the transcript to the red-highlighted moment the contestant emailed the fake API key.
4. **Live trap (60s):** ask a judge for a trap idea. Type it in Slack as `trap idea: …`. Simon builds the level, opens the PR, runs two contestants, posts the recap. One takes the bait on screen.
5. **Why Grokbots (20s):** Simon designs, runs, judges and reports on his own, on a schedule, across GitHub and Slack. That's an always-on agent doing a real job.
6. **Close (20s):** "Agent safety shouldn't be a research paper. It should be a game anyone can play."

**Backup:** pre-recorded video of step 4 at <link>, in case the live run is slow.
